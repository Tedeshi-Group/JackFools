# JackFools

Утилита, позволяющая вам использовать легальные возможности во время Jackbox Games.

## 🔥 Функционал

* Заполнение открытого лобби игры ботами, которые занимают слоты для живых игроков. Это можно использовать в случаях, когда вам не хватает игроков, чтобы запустить любимую игру.
* Специальная сеть ботов, которые будут симулировать зрителей, если вы хотите повысить активность на стриме, или использовать зрителей, чтобы они вам помогали в процессе игры.
